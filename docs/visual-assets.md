## Sequence-layer diagram

`assets/memory-flow.svg` is an editable vector diagram authored for the README.
It summarizes the existing code in `implementation/neural/layer.py`: projected
input density, causal auxiliary memory, nonlinear interaction and output with the
layer input residual. Drawn curves illustrate memory decay; they are not data.

Both assets have descriptive alternative text in the README. The diagram also
includes an SVG title and description. `docs/archive/README.before-visual-redesign.md`
preserves the immediately preceding README.
